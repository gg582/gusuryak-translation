# 낙서팔구도를 팔자각득(八子各得)으로 다시 읽기

낙서팔구도(洛書八九圖)는 **오팔정전도(五八井田圖)**의 형태로 그려진다.
7×7 정전(井田) 격자에 9개의 우물(井) 자리를 비우고, 그 주변 8칸에 1부터 40까지의 수를 배치한다.
이름에 내장된 이스터에그처럼, **각 우물이 8칸(八子)을 얻어 모두 같은 합 164를 만드는** 팔자각득 구조다.

---

## 1. 팔자각득의 기본 수치

| 항목 | 값 |
|---|---:|
| 사용하는 수 | 1부터 40까지, 각 1회 |
| 전체 수의 합 | 820 |
| 우물(宮)의 수 | 9개 |
| 각 우물이 얻는 칸(子) | 8개 |
| 각 우물의 합 | **164** |
| 9우물 중복 계수 합 | 164 × 9 = **1476** |

각 우물의 합 164는 공정 몫 규칙의 결과다.

```
164 = 8 × (40 + 1) / 2 = 전체 총합 820 × 8 / 40
```

즉 각 우물은 40개 수 전체의 **8분의 1씩**을 정확히 나눠 가진다.

---

## 2. 作(작)과 用(용)의 분리: 四十子作, 七十二子用

- **四十子作**: 1부터 40까지의 수가 도상에 정확히 한 번씩 적힌다. 고유 수의 총합은 820.
- **七十二子用**: 9개 우물 각각이 8칸을 얻으므로, 구조상 총 자리 수는 9 × 8 = 72.
- 둘의 차이 **72 − 40 = 32**는 인접 우물들이 공유하는 겹침 자리 수다.

중복 계수 방정식:

```
9 × 164 = 820 + D
1476 = 820 + D
D = 656
```

칸별 중복 차수는 다음과 같다.

| 중복 차수 | 칸 수 | 기여 |
|---|---:|---:|
| 1개 우물에만 속함 | 16 | 16 |
| 2개 우물에 속함 | 20 | 40 |
| 4개 우물에 속함 | 4 | 16 |
| 합계 | 40 | 72 |

16 + 40 + 16 = 72로, 9 × 8과 일치한다.

---

## 3. 9우물 배치: 각 우물이 8자를 얻는다

7×7 격자에서 9개 우물은 (홀수, 홀수) 좌표를 중심으로 하는 3×3 블록이고, 중심 칸은 비어 있다.
`reconstruct_milp.py`가 복원한 배치(`visualize.py`의 grid_data)는 다음을 만족한다.

- 1부터 40까지 정확히 한 번씩 사용
- 9개 우물 모두 주변 8칸의 합이 **164**

복원은 기존 관측 배열에서 **6칸만** 교정했다. 교정은 두 개의 3-싸이클로 이루어진다.

```
(0,4): 4 → 9,  (0,6): 9 → 13,  (2,6): 13 → 4
(1,4): 33 → 29, (2,5): 29 → 37, (5,0): 37 → 33
```

관측 배열에서 우물 합은 160, 163, 164, 164, 164, 165, 168이었고, 교정 후 9개 모두 164가 된다.

---

## 4. 五八의 이중 이스터에그

오팔정전도(五八井田圖)라는 이름에는 두 개의 수가 내장되어 있다.

- **八(8)**: 각 우물이 얻는 칸 수(八子) — 낙서y구도 계열의 y 규칙 그대로
- **五八 = 40**: 사용하는 수의 총개수(1~40)

이름 자체가 "40개의 수를 8칸짜리 9우물에 배치한다"는 설계 명세를 담고 있다.

---

## 5. 구수략 팔자각득과의 관계

`02-gakdeuk-series/팔자각득`의 구수략 계열 팔자각득은 **5개 궁에 각 8자씩** 배치하고 각 궁의 합을 **164**로 맞춘다(5 × 164 = 820, 정확 분할).

| 항목 | 낙서팔구도(오팔정전도) | 구수략 팔자각득 |
|---|---|---|
| 그룹 수 | 9개 우물 | 5개 궁 |
| 그룹당 셀 수 | 8칸 | 8자 |
| 그룹 합 | 164 | 164 |
| 사용 수 | 1~40 | 1~40 |
| 겹침 | 있음(72용/40작) | 없음(40용/40작) |

둘은 같은 **y = 8, T = 164** 규칙의 두 구현이다.
낙서팔구도가 9궁 공간에 겹쳐 펼친 버전이라면, 구수략 팔자각득은 5궁으로 정확히 나눈 버전이다.

---

## 6. 사오도(四/五道) 관점에서 보기

낙서팔구도는 9개 우물이 3×3으로 배치된 공간(사도)에, 8칸이라는 팔도(八道) 부분합 불변량을 실현한 구조다.
각 우물의 8칸은 3×3 블록에서 중심을 뺀 나머지이며, 중심의 빈칸이 우물(井)의 구멍을 이룬다.
이웃 우물이 변을 공유해 겹치는(鄰星相兼에 해당) 속에서도 모든 우물의 합이 164로 유지되는 점이 팔자각득의 핵심이다.

---

## 7. 요약

| 관점 | 요약 |
|---|---|
| 조합 구조 | 40개 수 → 9개 우물, 각 우물 8칸 |
| 불변량 | 모든 우물의 합 = 164 |
| 생성 원리 | 공정 몫: 전체 총합 × 8/40 |
| 공간 구조 | 7×7 정전 격자, 9개 우물 중심 공백 |
| 겹침 | 72용 / 40작, 단순 중복 32자리 |
| 이름의 수 | 八 = 칸 수, 五八 = 40 = 수의 개수 |

낙서팔구도는 팔자각득이라는 이름 아래, 1부터 40까지의 수를 아홉 우물에 8칸씩 겹쳐 담은 조합 설계다.
164는 각 우물이 전체에서 차지하는 정확한 몫이며, MILP 복원은 관측 배열의 6칸만 바꿔 그 설계를 복원한다.
