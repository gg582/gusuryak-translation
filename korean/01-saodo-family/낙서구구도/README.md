# 낙서구구도 분석

낙서구구도는 낙서 정규마방진의 3x3 중심 배열에, 각 중심수마다 여덟 개의 외곽수를 붙여 만든 1~81 마방진이다. 각 묶음은 중심수 하나와 주변 여덟 수로 이루어지며, 아홉 묶음의 합은 모두 369가 된다.

```text
4 9 2
3 5 7
8 1 6
```

(도상의 궁 배치는 위 낙서 배열을 상하로 뒤집어 八·一·六 / 三·五·七 / 四·九·二 순으로 둔 것이다.)

## 전체 합과 목표 상수

1부터 81까지의 합은 다음과 같다.

```text
1 + 2 + ... + 81 = 81 x 82 / 2 = 3321
```

이를 아홉 묶음으로 나누면 한 묶음의 목표 합은 다음과 같다.

```text
3321 / 9 = 369
```

따라서 중심수가 `n`인 묶음의 주변 여덟 수는 반드시 다음 합을 가져야 한다.

```text
주변합 = 369 - n
```

## 원문 도상 판독과 MILP 교정

배치 데이터는 원문 도상을 좌상단부터, 각 궁은 중심수와 둘레(윗쪽 왼칸부터 시계방향) 순으로 판독한 것을
`reconstruct_milp.py`가 제약(각 궁 합 369, 10~81 각 1회, 중심수 고정)에 맞게 최소 교정으로 복원한 결과다.
판독 대비 교정은 4건이다.

| 궁 | 교정 내용 |
|---|---|
| 四 (중심 4) | 둘레 마지막 칸 판독 누락 → **47** |
| 三 (중심 3) | 둘레 5번째 칸 **71 → 19** |
| 七 (중심 7) | 둘레 4번째 칸 **3 → 31** (중심수가 둘레에 섞인 오독) |
| 六 (중심 6) | 둘레 마지막 칸 **38 → 30** (38이 두 번 판독된 것의 하나) |

## mod 9 횡단 구조

이 배치의 핵심 생성 원리는 91 보수쌍이 아니라 **mod 9 잉여 분배**다.

- 각 궁의 둘레 8수는 mod 9 잉여류 **8개를 정확히 한 번씩** 갖는다.
- 단, **자기 중심수의 잉여류는 빠진다**. (중심수가 그 잉여류의 대표이기 때문)
- 따라서 묶음 전체(중심 + 둘레)는 mod 9 잉여 0~8을 각각 정확히 한 번씩 갖는 완전 횡단 집합이다.
- 잉여의 합이 0+1+...+8 = 36 ≡ 0 (mod 9)이므로, 각 묶음의 합은 9의 배수가 되고 369 = 9 x 41이 자연스럽다.

| 궁(중심) | 둘레에 없는 mod 9 잉여 |
|---|---:|
| 八 (8) | 8 |
| 一 (1) | 1 |
| 六 (6) | 6 |
| 三 (3) | 3 |
| 五 (5) | 5 |
| 七 (7) | 7 |
| 四 (4) | 4 |
| 九 (9) | 0 |
| 二 (2) | 2 |

잉여류 r (mod 9)에 속한 9개의 수 {r, r+9, ..., r+72}는 정확히 9개 궁에 하나씩 퍼져 있고,
중심수가 r인 궁에는 그 수들 가욱 중 r 자신(중심수)만 남는다.

## 해석

낙서구구도는 단순히 둘레합을 같게 만든 도상이 아니다. 중심 낙서마방진의 9개 수를
mod 9 잉여의 기준점으로 삼고, 외곽 72개 수를 "어떤 궁도 자기 잉여는 갖지 않으며
다른 잉여는 정확히 하나씩 갖도록" 횡단 배열한 설계다.

```text
각 묶음 = 완전한 mod 9 횡단 집합 (9개 수, 잉여 0~8 각 1회)
묶음 합 = 369 = 9 x 41
```

위 4건의 판독 교정(47, 19, 31, 30)은 전부 이 mod 9 횡단 규칙이 요구하는 값들이다.
즉 원문의 각득 합 369와 mod 9 구조는 서로 동치의 제약이며, MILP 복원은 둘을 동시에 만족한다.
