## 양·음 짝의 관계

| 짝 | 관계 |
| --- | --- |
| 사사도 양수도 → 사사도 음수도 | 같은 행 집합·열 집합(행·열 재배치 관계) |
| 오오도 양수도 → 오오도 음수도 | 회전·반사·보수·행열 재배치로 옮겨지지 않음 |
| 육육도 예시 1 → 육육도 예시 2 | 회전·반사·보수·행열 재배치로 옮겨지지 않음 |
| 행수도 양수도 → 행수도 음수도 | 회전·반사·보수·행열 재배치로 옮겨지지 않음 |
| 역수도 양수도 → 역수도 음수도 | 회전·반사·보수·행열 재배치로 옮겨지지 않음 |
| 구수도 → 구수음도 | 회전·반사·보수·행열 재배치로 옮겨지지 않음 |
