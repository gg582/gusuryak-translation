# 육육도(六六圖)

차수: 6×6

[원본 기준] 6×6 정상 마방진 두 예시. 두 예시 모두 행·열·대각선 합이 111이다. 둘은 회전·반사로 서로 옮겨지지 않는 다른 해이지만, 같은 구성 원리를 공유한다.

## 구성 원리

두 예시는 같은 원리로 짜여 있다. 6×6을 2×2 블록 아홉 개로 나누고, 낙서 L = (4 9 2 / 3 5 7 / 8 1 6)에서 블록 자리에 해당하는 수를 L이라 하면, 각 칸의 수는 다음과 같다.

    v = L + 9k,  k ∈ {0, 1, 2, 3}

곧 각 블록에는 L, L+9, L+18, L+27의 네 수가 한 번씩 들어간다. 예를 들어 왼쪽 위 블록(L=4)에는 4, 13, 22, 31이, 가운데 블록(L=5)에는 5, 14, 23, 32가 들어간다. 따라서 블록의 합은 4L+54이고, 아홉 블록의 합 70 90 62 / 66 74 82 / 86 58 78은 다시 낙서의 배치를 이룬다.

k를 모은 6×6 배열은 모든 가로, 세로, 주대각선의 합이 9이다. 낙서 부분이 각 줄에 2×15=30을 주고 k 부분이 9×9=81을 주므로, 줄의 합은 30+81=111이 된다.

두 예시는 블록마다 같은 네 수를 쓰고, 블록 안에서 k를 놓는 방식만 다르다. 6차는 4로 나누어 2가 남는 차수이므로, 중심에 대해 마주 보는 두 칸의 합이 늘 37인 대칭형 마방진과, 끊어진 대각선까지 합이 모두 111인 범대각 마방진이 존재하지 않는다. 따라서 두 예시는 대칭형도 범대각도 아니다.

예시 1의 k 배열:

```
1 2 1 2 1 2
3 0 3 0 3 0
1 2 1 2 1 2
3 0 0 3 3 0
1 2 1 2 1 2
0 3 3 0 0 3
```

예시 2의 k 배열:

```
0 1 3 2 3 0
2 3 1 0 1 2
0 2 2 3 2 0
3 1 0 1 1 3
1 2 2 3 0 1
3 0 1 0 2 3
```
