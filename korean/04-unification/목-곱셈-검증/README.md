# 木與木相摩則然 — '목×목 → 화' 곱셈 해석 전수 검증

하도사오도 원문의 "兩木相摩 … 木與木相摩則然"을 **곱셈**(相摩 = 곱)으로 읽으면 목 그룹끼리의 곱이 화 그룹을 만든다는 가설이 나온다. 이 문서는 그 가설을 구수략 마법진 문서에 실린 그래프 17종(낙서육고도는 이론적으로만)에 같은 방식으로 돌려 본 결과다.

- 스크립트: [`wood_product_audit.py`](wood_product_audit.py) (외부 의존성 없음)
- 전체 출력: [`audit_report.txt`](audit_report.txt)
- 원문 재해석 본문: [하도사오도 원문과 재해석](../../01-saodo-family/하도사오도-지만-사실-5-컬러링-문제/docs/source_text_reinterpretation.ko.md)

라벨은 구수략 원문 그대로 `n ≡ 1 수(水), 2 화(火), 3 목(木), 4 금(金), 0 토(土) (mod 5)`이다.

## 1. 결론 요약

1. **곱셈 가설은 성립하지 않는다.** mod 5에서 `木·木 = 3·3 = 9 ≡ 4`, 즉 **금(金)** 이다. 궁 안의 목·목 쌍 124개 전부에서 곱은 금이었고 화는 0개였다. 이는 그래프와 무관한 대수적 사실이므로 어떤 배치에서도 바뀌지 않는다.
2. **다른 법(modulus)으로 줄여도 의미 있는 신호는 없다.** 곱을 mod N(사용한 수의 최댓값), mod C(보수합)로 줄여 그 도형의 화 숫자와 맞춰 보면 각각 8/124, 34/124가 적중했다. 기저율 기대값은 약 24.5다. mod C의 초과분은 단측 이항 p ≈ 0.025이지만, 세 가지 법을 사전 근거 없이 시험했으므로 보정하면 p ≈ 0.075가 되어 유의하지 않다. 그리고 `ab mod C`의 오행은 몫 k에 따라 `4 − k·C (mod 5)`로 바뀌므로 구조적 이유가 없다.
3. **원문 세 구절을 정확히 설명하는 것은 덧셈 쪽, 곧 보수쌍이다.** 하도사오도의 보수합은 `C = 21 ≡ 1 (mod 5)`이므로 대합 `n ↦ 21 − n`은 오행을 `수↔토, 화↔금, 목↔목`으로 보낸다. 이 대합의 궤도 유형은 정확히 세 가지인데, 원문의 **水土相涵 · 金火相守 · 兩木相摩**가 바로 그 세 유형을 하나도 빠짐없이 나열한 것이다. 목은 이 대합의 유일한 고정점(자기보수)이고, 그래서 "두 나무(兩木)"가 서로 짝을 이룬다. 자세한 내용은 원문 재해석 문서에 있다.
4. **곱셈 관점에서 실제로 나오는 깔끔한 구조**는 다음과 같다. 보수쌍의 곱 `n·(C−n) ≡ r(1−r) (mod 5)`는

   | 쌍 유형 | 곱의 오행 |
   |---|---|
   | 水土 (相涵) | 토 |
   | 火金 (相守) | **목** |
   | 木木 (相摩) | **금** |

   이다. 즉 相守 쌍의 곱은 목, 相摩 쌍의 곱은 금이 되어 두 구절이 곱셈으로 서로의 원소를 맞바꾼다. 수토 쌍은 토(곱셈의 영원)로 흡수된다. 화는 `木³ = 27 ≡ 2` 또는 `木·金 = 12 ≡ 2`로만 나온다. 원문의 "則然(불붙는다)"을 곱의 결과로 읽을 근거는 되지 않지만, 하도사오도 궁 단위 곱(mod 5)이 `목궁 → 수 (3⁴ ≡ 1)`, `화금궁 → 금`, `수토궁 → 토`로 정리된다는 점과 함께 기록해 둔다.

## 2. mod 5 곱셈표

```
     수  화  목  금  토
  수  수  화  목  금  토
  화  화  금  수  목  토
  목  목  수  금  화  토
  금  금  목  화  수  토
  토  토  토  토  토  토
```

목의 거듭제곱: `木¹ = 목, 木² = 금, 木³ = 화, 木⁴ = 수`. 목(3)은 곱셈군 (ℤ/5)\*의 생성원이다.

## 4. 유의미한 관찰

### 4.1 원문 세 구절은 C ≡ 1 (mod 5) 계열의 보수쌍 분류표다

보수합이 `C ≡ 1 (mod 5)`일 때, 그리고 그때만 목이 자기보수가 되어 `水土 / 火金 / 木木` 세 유형이 생긴다. 하도사오도, 낙서사구도, 낙서팔구도, 하도칠·팔·구오도, 낙서육고도가 모두 이 계열이다. 즉 "兩木相摩"는 사오도 한 장에만 해당하는 수사가 아니라, 사오도를 원형으로 하는 하도 계열 전체에 그대로 통한다.

- **하도사오도**: 다섯 궁이 모두 보수쌍 두 개로 정확히 쪼개지고, 궁의 오행 구성이 상·우 = 火金(相守), 중·하 = 水土(相涵), 좌 = 木木(相摩)이다.
- **낙서사구도**: 아홉 궁 모두 보수쌍 두 개로 정확히 쪼개지며, 쌍 유형은 세 가지뿐이다.
- **하도팔오도**: 궁의 오행 구성(상 화4 금4, 좌 목8, 중 수4 토4, 우 화4 금4, 하 수4 토4)이 하도사오도와 **같은 위치에서 같은 유형**으로 반복된다. 원문 세 구절이 팔자각득에서도 궁 단위로 그대로 성립한다.

### 4.2 다른 계열에서는 목의 짝이 바뀐다

- `C ≡ 0` (범수용오도·장책용칠도·중괘용팔도·기책용팔도): 목의 보수 짝이 **화**다. 이 계열에서는 목 하나와 화 하나가 보수쌍을 이룬다. "목에서 화가 나온다"는 연결이 덧셈 보수로는 이 계열에서만 생기지만, 이는 "목과 목"이 아니라 "목과 화"의 관계다.
- `C ≡ 2` → 목↔금, `C ≡ 3` → 목↔토, `C ≡ 4` → 목↔수.

### 4.3 공간적 동거 검사

목이 둘 이상 든 궁에 화가 함께 있는지도 확인했다. 하도사오도의 목궁(좌)에는 화가 없다. 원문이 말하는 "불이 붙는다"는 사오도의 배치에 화 원소로 나타나 있지 않으므로, 이 구절은 배치 규칙이 아니라 **인용된 비유**(《莊子·外物》)로 보는 것이 맞다.

## 5. 판정

| 해석 | 판정 |
|---|---|
| 相摩 = mod 5 곱, 木·木 → 火 | **기각** (항상 金, 124/124) |
| 相摩 = 곱을 mod N 또는 mod C로 줄임 | **유의하지 않음** (다중비교 보정 후) |
| 相涵·相守·相摩 = 보수 대합 `n ↦ C−n`의 세 궤도 유형 | **채택** (사오도 5/5궁, 사구도 9/9궁, C ≡ 1 계열 전체) |
| 則然·則流 = 《莊子》 인용에 의한 오행 비유 | 채택 (원문 재해석 문서 참조) |
| 곱셈 부수 구조: 火金 쌍의 곱 → 木, 木木 쌍의 곱 → 金 | 대수적 사실로 기록, 원문 해석 근거로는 쓰지 않음 |
