# 낙서 확장 일반화: 보수 대합의 정확한 공통분모

## 결론

낙서 계열의 공통분모는 단순히 “합이 일정하다”가 아니다. 다음 두 대합을 맞물리게 하는 **등변 확장 원리**다.

\[
\tau:P\to P,\qquad \kappa_S:V\to V,\quad \kappa_S(x)=S-x,
\]

\[
v\circ\tau=\kappa_S\circ v.
\]

여기서 `P`는 위치 집합, `τ`는 중심대칭 등 위치 대합, `V`는 값 집합,
`κ_S`는 합 `S`의 값 보수 대합, `v`는 위치에 값을 배정하는 함수다.

이 등식이 성립하면 모든 위치 `p`에 대해 자동으로

\[
v(p)+v(\tau p)=S
\]

가 된다. 역으로, 모든 위치쌍의 합이 `S`이면 위 등식이 성립한다. 즉 이는
대척보수의 필요충분 조건이다.

## 3×3 낙서의 원형

표준 낙서

\[
\begin{matrix}
4&9&2\\3&5&7\\8&1&6
\end{matrix}
\]

는 중심 반전에 대해 `1↔9`, `2↔8`, `3↔7`, `4↔6`이며 각 쌍의 합은 10이다.
중앙 `5`는 위치 대합과 값 보수 대합의 유일한 고정점이다. 따라서 표준 낙서는
`S=10`인 등변 배정의 가장 작은 예다.

## 육고도에 적용

육고도에서는 `通加洛書數六倍`가 낙서 계수 `k`를 고리 크기 `6k`로 올린다.
그러므로 기본 낙서의 `k↔10-k`는

\[
6k\leftrightarrow6(10-k),\qquad6k+6(10-k)=60
\]

가 된다. 來積法의 `54+6=60`은 바로 이 첫 고리 보수쌍이다.

또한 중심을 비우면 위치는 270개, 즉 135개 대척쌍으로 분해된다. 값 1…270은
`κ_{271}(x)=271-x` 아래 135개 보수쌍으로 분해된다. 따라서 **등변 확장 원리**를
육고도의 최소 배정 원리로 채택하면

\[
v(c)+v(-c)=271
\]

은 선택사항이 아니라 필연이다.

반대로 271칸·虛一·고리·축·변의 합 조건만으로는 등변성이 나오지 않는다. 실제
육고도 감사 반례는 그 집계를 유지하면서 등변성을 깨뜨린다. 그러므로 역사적 질문은
“보수쌍이 수학적으로 가능한가?”가 아니라 “저자가 이 등변 확장 원리를 배정 규칙으로
채택했는가?”다.

현재 책 내부의 증거는 이를 강하게 지지한다. 그러나 육고도 본문에 위치 대합과 값 보수
대합을 직접 연결하는 문장이 확인되기 전까지는, 이는 강한 복원 원리이지 직접 전사 조건은 아니다.
