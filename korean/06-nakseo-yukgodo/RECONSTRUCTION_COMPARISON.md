# 낙서육고도 재구 가설의 정당성 비교: 대척보수 vs 고리별 연속값

이 문서는 洛書六觚圖의 두 개연성 있는 재구 가설을 나란히 놓고, 각각의 원문 근거·수치 성질·취약점·판가름 기준을 비교한다. 어느 쪽도 확정된 원문 조건이 아니라는 전제에서 출발한다.

- **가설 A — 대척보수**: 대척(점대칭) 위치의 두 값이 합 271의 보수쌍. 상위 `yukgodo/` 패키지와 `output/solution.json`의 증인해가 이 가설을 채택한다.
- **가설 B — 고리별 연속값**: 고리 k가 연속 구간 3k(k−1)+1 … 3k(k+1)을 받고, 값이 원주를 따라 연속 진행. [yukgodo2/](yukgodo2/)가 이 가설을 구현한다.

## 1. 공통 기반 (확정 원문·기하)

두 가설이 공유하는, 원문과 계산으로 직접 지지되는 부분:

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 총 칸 수 | 271 | 《漢書·律曆志》 二百七十一枚而成六觚; 來積法 252+19 |
| 虛一 뒤 | 270 | 虛一則二百七十數, 共積二百七十 |
| 외주 | 54 | 枚外周五十四數 = 蘇林 注 六九五十四 |
| 변당 칸 | 10 | 來積法 54+6=60, 60÷6=10 (一觚數) |
| 中觚 | 19 | 來積法 2×10−1=19 (中觚數) |
| 고리 크기 | 6k | 以筭法則係以六, 逓加洛書數六倍 |
| 고리 수 | 9 | 來積法 54÷6=9 |

이 층위까지는 두 가설이 완전히 일치하며, 차이는 **값의 배치**에서만 생긴다.

## 2. 원문 근거의 층위 비교

| 근거 | 가설 A (대척보수) | 가설 B (연속값) |
| --- | --- | --- |
| 來積法 전체 | 중립 — 적수(칸 수) 계산이라 배치 무관 | 중립 — 동일 |
| `逓加`(차례로 더하기) 어휘 | 간접 — 낙서 수의 6배 고리로 읽음 | 친화 — 순차 축적의 어휘가 고리별 연속 축적과 맞물림 |
| 六包一 급수 (교우사 판본 11쪽: 1+(6+12+…+54)) | 중립 — 칸 수 구조만 일치 | 칸 수 구조와 항 대 항 일치 — 다만 급수는 칸 수이지 값 배치가 아님 |
| `洛書`六觚圖라는 명명 | 강한 지지 — 낙서의 본질이 대척 보수쌍(합 10, 중심 5) | 지지 없음 — 낙서 성질을 쓰지 않아 명명이 무의미해짐 |
| 洛書九九圖 등 계열 도상의 보수쌍 구성 선례 | 강한 지지 — 보수쌍이 실제 구성 규칙으로 쓰임 | 위반 — 균형 구성 문법과 충돌 |
| 圓束樣式 (중심 공백·쌍 단위, 교우사 판본 48쪽) | 지지 — 중심 공백 뒤 대척쌍 구조의 최소 선례 | 중립 — 중심 공백만 공유 |
| 逓加洛書數六倍의 6배 승격 (54+6=60) | 지지 — `k↔10-k`가 `6k↔6(10-k)`로 승격 | 중립 |
| 값 배치의 직접 명령문 | 없음 | 없음 |

## 3. 측정 지표 비교

`yukgodo2/compare.py`가 두 해를 같은 기하 지표로 측정한다 (전수치: [yukgodo2/output/comparison.md](yukgodo2/output/comparison.md)). A 측 증인해는 시드 1715(페널티 6.0 = 이론적 하한)이며, 영문 트리의 증인해는 더 긴 탐색의 같은 시드 해라 섹터·광선의 배열 순서만 다르고 다중집합은 같다.

### 균형 지표 (최대 편차)

| 지표 | 목표 | A 최대 편차 | B 최대 편차 |
| --- | ---: | ---: | ---: |

B의 섹터합은 5385, 5670, 5955, 6240, 6525, 6810의 등차 수열(공차 285)이고, 변합은 2215..2611로 단조 증가한다.

### 대척쌍·꼭짓점

| 지표 | A | B |
| --- | ---: | ---: |
| 대척쌍 합 = 271인 쌍 (135 중) | 135 | 0 |
| 대척쌍 합 범위 | 271–271 | 5–513 |
| 꼭짓점 합 (구조적 목표 813) | 813 | 1437 |

B의 이 지표들은 시작점 정규화와 무관하다: D6(회전·반사) 작용은 섹터·광선·변·축 합의 다중집합, 대척쌍 합의 다중집합, 꼭짓점 합을 모두 보존하므로, 위 편차는 좌표 규약의 인공물이 아니라 가설 자체의 성질이다.

## 4. 수치가 말하는 것

- **A의 식별력 구조**: A를 채택하면 고리합 813k·축합 2439·꼭짓점 합 813은 자동 귀결이라 식별력이 없고, 최적화가 실제로 산출한 것은 섹터·광선·변의 균형이다. 해공간은 135!×2¹³⁵으로 거대하며, 서로 다른 시드의 증인해는 0/270칸만 일치한다 — 특정 원배열 식별력은 없다.
- **B의 반균형**: B는 모든 균형 지표에서 구조적으로 벗어난다. 값이 고리를 따라 오름차순으로 누적되므로 어느 회전·반사를 택해도 한쪽 섹터에 작은 값, 반대쪽에 큰 값이 몰린다. 이것은 정규화의 문제가 아니라 "연속 축적"이라는 가설의 필연이다.

## 5. 각 가설의 취약점

**가설 A (대척보수)**

- 원문에 `對觚相合二百七十一` 류의 직접 위치-값 명령이 전사되지 않았다.
- 반례 감사(`ANTIPODAL_AUDIT.md`, `NAKSEO_FAMILY_EVIDENCE.md`): 값 집합·고리합·축합·변합·섹터/광선 균형을 모두 유지하면서 대척합을 깨는 배치가 존재한다 — 집계 조건은 대척보수를 논리적으로 강제하지 않는다.
- 증인해의 거대한 다수성은 원배열 식별력 부재를 뜻한다.

**가설 B (고리별 연속값)**

- `洛書六觚圖`라는 명명을 무의미하게 만든다 — 낙서의 어떤 성질(보수쌍, 균형)도 사용하지 않는다.
- 《구수략》의 형제 도상(낙서 3×3, 洛書九九圖, 九子角得 등)이 모두 균형·보수 구성물인데, B는 반균형이 구조적 필연이다.
- B를 지지하는 `逓加`·`六包一` 근거는 전부 칸 수(積) 산법에 관한 것이지, 값 1..270의 배치에 관한 것이 아니다. 來積法이 적수 계산이라는 판정은 B에게도 A에게도 중립적이다.
- 연속값 배치는 항상 구성 가능하므로 Z3 만족 가능성 자체는 증거가 되지 못한다.

## 6. 무엇이 판가름하는가

- **더 선명한 판본의 실제 배치 판독**: 실제 도안이 판독되면, (i) mod N 잉여류 채색이 회전180°에서 r↔S−r 대칭을 보이는지로 A를 검사·반증할 수 있고, (ii) 각 고리의 값 집합이 연속 구간을 이루는지로 B를 검사·반증할 수 있다. 두 검사는 서로 독립이며 둘 다 기각될 수도 있다.
- **직접 명령문의 발견**: 위치-값 대응을 지시하는 문구가 새로 전사되면 등급이 바뀐다.
- **병편 산법의 추가 해독**: `三積算子` 계열 문제에서 값 배치 절차가 확인되면 B 류의 순차 축적 해석이 강해진다.

## 7. 판정

둘 다 미확정이다. 정당성의 성격이 다르다:

- **A**는 책 내부 정합성(명명·계열 선례·쌍 구조)이 강한 후보이지만, 직접 전사가 없고 집계 조건으로부터 논리적으로 도출되지 않는다.
- **B**는 산법 절차상 가장 단순한 후보이고 칸 수 급수와 정확히 맞물리지만, 도안의 명명과 책 전체의 균형 문법과 충돌하며, 측정된 모든 균형 지표에서 구조적으로 벗어난다.

현재 텍스트 증거만으로는 A를 "강한 내부 복원 후보" 이상으로 올릴 수 없고, B를 "단순 절차 후보" 이상으로 올릴 수 없다. 어느 쪽도 원문의 실제 배치로 단언할 수 없다.

재현: A는 `python3 main.py`(상위), B는 `python3 yukgodo2/solver.py`, 지표 비교는 `python3 yukgodo2/compare.py`.
