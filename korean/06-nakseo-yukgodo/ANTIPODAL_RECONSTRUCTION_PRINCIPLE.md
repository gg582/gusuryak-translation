# 문헌 내적 대척보수 복원원리

## 판정

`v(c)+v(-c)=271`이라는 한 줄의 위치-값 명령은 현재 확인된 육고도 전사에 없다. 그러나 이것을 근거 없는 현대 제약 또는 약한 추측으로 부르는 것도 정확하지 않다. **洛書六觚圖의 대척보수 조건은 책 내부의 여러 독립 사실이 한 대응으로 수렴하는 강한 복원원리**로 취급한다.

핵심 구별은 다음과 같다.

\[
\text{직접 전사 명령 없음}\;\not\Rightarrow\;\text{문헌 내적 근거 없음}.
\]

## 서로 독립적인 근거

| 근거 | 판정 | 대척보수 원리와의 관계 |
| --- | --- | --- |
| 저자의 명명 `洛書六觚圖` | 직접 원문 | 육고를 독립 산가지 도형이 아니라 책의 낙서 원리 아래 읽게 하는 1차 명명 증거 |
| `數原第一`의 `併上下數共一十一` | 직접 원문 | 하도 1…10의 양끝을 보수쌍으로 묶어 다섯 격 각각에 11을 만드는 직접 산술 선례 |
| `數原第一`의 낙서 3×3 | 직접 도상·원문 | 대척 위치에서 `4+6=9+1=2+8=3+7=10`, 중심 5 고정: 위치 대합과 값 보수의 직접 결합 |
| `通加洛書數六倍` | 직접 원문 | 낙서 수를 6배한 9개 고리의 구조를 명시 |
| `54+6=60` | 내적법 계산으로 확정 | `6k+6(10-k)=60`인 낙서 보수대합의 6배 승격을 실제 첫·끝 고리에 사용 |
| 다른 `洛書…圖`의 보수대합 구성 | 책 내부 선례 | 洛書 계열에서 보수쌍이 사후 관찰이 아니라 구성 수법으로 쓰임 |
| `虛一` 뒤의 육고 기하 | 기하적으로 확정 | 270 위치는 정확히 135개의 중심대칭 대척쌍으로 분할 |
| 값 `1…270` | 값집합이 확인되면 산술적으로 확정 | 정확히 135개의 `x↔271-x` 보수쌍으로 분할 |
| `圓束樣式`의 중심 공백 7칸 | 책 내부의 구조적 보조증거 | `7-1=6=2×3`의 중심공백·대척쌍 구조를 육고의 `271-1=270=2×135`와 같은 방향으로 제시 |

따라서 위치 대합과 값 보수대합을 연결하는 최소 공통 표현은 등변성이다.

\[
v\circ\tau=\kappa_{271}\circ v,
\qquad \kappa_{271}(x)=271-x.
\]

이 원리를 채택하면 모든 채워진 위치에서

\[
v(c)+v(-c)=271
\]

이 자동으로 따른다. 135개의 위치쌍과 135개의 값쌍 사이에는 남거나 부족한 항이 없다.

## 반례 감사의 올바른 뜻

대척 조건을 제거한 솔버는 값집합, 고리합, 축합, 변합, 섹터·광선 균형을 보존하면서 대척보수를 깨는 반례를 찾는다. 이것은

\[
\text{집계 제약들}\;\not\Rightarrow\;v(c)+v(-c)=271
\]

을 보일 뿐이다. 즉 대척보수가 다른 합 제약의 우연한 산물이 아니라, 낙서 계열의 구성문법에서 별도로 채택해야 하는 원리임을 분명히 한다. 반례는 역사적 근거를 부정하지 않으며, 직접 전사 명령이 아직 없다는 경계만 유지한다.
