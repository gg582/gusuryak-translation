# 《구수략》의 등변성 사용 범위 감사

## 기준

이 감사에서 말하는 등변성은 위치 대합 `tau`와 값 보수 `kappa_S(x)=S-x`가

\[
v\circ\tau=\kappa_S\circ v
\]

를 만족하는 경우다. 즉 대응 위치의 값 합이 상수 `S`인 배정이다. 이는 보수쌍을 단지 같은 묶음에 넣는 구성과 구별한다.

## 확인 가능한 목록

| 범주 | 도안과 단위 | 결과 | 증거 등급 |
| --- | --- | --- | --- |
| 정확한 위치-값 등변성 | 洛書九九圖·五九圖·七九圖의 3×3 제어배열 | 각 4대향쌍 합 10, 중앙 5 | 저장된 도상 데이터에서 직접 확인 |
| 정확한 위치-값 등변성 | 九子各得의 중궁 3×3 | 4쌍 합 46, 중앙 23 = 46/2 | 직접 확인 |
| 정확한 국소 등변성 | 重卦用八圖의 두 가로진 | 좌우 8쌍 전부 합 65 | 직접 확인 |
| 보수쌍 구성, 전면 등변성 아님 | 洛書九九圖의 외곽 | 합 91의 36쌍을 실제 구성에 사용; 확장 전 셀 대척배정은 불성립 | 직접 확인 |
| 보수쌍 분배·재결합 | 重卦用八圖의 나머지 진형 | 합 65 쌍을 진형 사이에 분할·분배 | 구조 확인 |
| 부분적/음성 대조 | 侯策用九圖 | 36 위치쌍의 합 분포: 67:1, 68:1, 72:7, 73:16, 74:9, 75:1, 78:1 | 전면 등변성 불성립 |
| 음성 대조 | 範數用五圖 | 4 대향쌍의 합 분포: 9:2, 11:2 | 전면 등변성 불성립 |

따라서 이 책에는 등변성이 한 번의 우연한 패턴이 아니라, 적어도 세 가지 방식으로 반복된다: (1) 낙서 제어배열의 중심대칭, (2) 국소 도형의 위치-값 보수배정, (3) 보수쌍을 이용한 합 구성과 재분배. 동시에 侯策用九圖와 낙서 확장 셀의 음성 사례는 저자가 **모든** 도안에 전면 등변성을 기계적으로 적용하지 않았음을 보인다.

## 來積法 전사 수정 후의 육고도 가설

전사 기준은 다음과 같다.

- `六而一得一十乃每一包敉也`: 해당 글자는 `危`가 아니라 `包`이다. `包敉`의 산학 기능은 아직 미해결이며, 이 수정은 계산망의 수치를 바꾸지 않는다.
- `今有方箭束一百四十四隻問外周幾何`: `隻`은 짝의 한쪽, 외짝을 세는 단위다. 그러므로 圓束樣式의 중심 공백과 여섯 주변 위치를 함께 읽을 때, 쌍의 **개별 구성원**을 세는 구조를 강하게 시사한다.

따라서 수정된 가설은 다음과 같이 더 엄격하고 더 강하다.

1. 來積法은 `271=19+2((10+18)/2×9)`라는 중고와 두 梯田의 **기하적 적수 계산**을 강하게 지지한다.
2. `隻`과 圓束樣式은 중심 공백 뒤 대척쌍의 **외짝 단위**라는 내부 선례를 보강한다.
3. 책 전체의 확인 가능한 도상은 등변성을 제어배열·국소 배정·보수쌍 구성으로 반복 사용한다.
4. 그러나 육고도 본문에는 아직 `對觚相合二百七十一` 같은 직접 명령이 없다. 따라서 `v(c)+v(-c)=271`은 직접 전사가 아니라, 위 증거를 종합한 강한 복원 조건이다.

핵심 변화는 “쌍을 단지 셀 수 있다”가 아니라, `隻`이 **쌍의 한쪽을 셈**으로써 위치쌍과 값쌍을 대응시키는 독해에 더 가까워졌다는 점이다. 다만 이 언어적 보강은 값 합 271을 단독으로 산출하지 않으므로, 반례 감사가 정한 논리적 경계는 유지한다.
