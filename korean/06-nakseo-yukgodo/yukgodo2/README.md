# yukgodo2 — 고리별 연속값 재구 (六包一/逓加 계열)

낙서육고도의 또 다른 개연성 있는 재구를 다루는 독립 미니 리포. 상위 프로젝트의 대척보수 복원(`../yukgodo`)과는 별개의 후보다.

## 가설

원문이 직접 지지하는 산술 구조:

- 逓加의 고리 크기 6k (k = 1..9), 6×(1+…+9) = 270
- 來積法 사슬: 54+6=60, 60÷6=10, 2×10−1=19, (10+18)×9=252, 252+19=271
- 虛一: 중심을 비워 270칸
- 六包一 급수(《구수략》 곤책 교우사 판본 11쪽): 1+(6+12+…+54) = 271

값 배치를 위한 재구 가설:

- 값 1..270을 한 번씩 배치
- 고리 k는 연속 구간 3k(k−1)+1 … 3k(k+1)을 받는다 (고리 1: 1..6, …, 고리 9: 217..270)
- 각 고리 안에서 값은 원주를 따라 연속적으로 진행한다

고리의 시작점과 회전 방향은 회전 대칭의 정규화일 뿐 원문 지시가 아니다. 이 가설의 고리합은 18k³+3k이며, 대척보수 가설의 813k와 다르다.

## 실행

```bash
python3 solver.py   # output/ 에 solution.json, report.md, reconstruction.png 생성
```
