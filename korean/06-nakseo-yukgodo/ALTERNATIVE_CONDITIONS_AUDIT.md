# 대척보수 이외 조건의 경쟁 실험

## 목적과 공통 기준

이 감사는 `v(c)+v(-c)=271`을 유일한 출발점으로 고정하지 않는다. 다음 여섯 조건군을 서로 교체해 구현하고, 각 경우에 `1…270`의 일회 사용, 중심 `虛一`, 271칸 육각 격자, 9고리를 공통으로 유지했다.

실행:

```bash
python3 tests/test_alternative_models.py
python3 -m yukgodo.alternative_models
```

비교값 `balance_penalty_side_wedge_ray`는 기존 증인해와 같은 변·섹터·광선 목표에 대한 절대편차 합이다. 낮을수록 그 **현대적 균형 목표**를 덜 깨뜨린다는 뜻일 뿐, 원문 의도를 자동으로 뜻하지는 않는다. `axis_deviation`과 `ring_deviation_from_813k`는 별도 보고한다.

## 구현한 경쟁 모델과 첫 실행값

| 모델 | 정확히 강제한 조건 | 변·섹터·광선 편차 | 축 편차 | 고리 `813k` 편차 | 대척합 271인 쌍 |
| --- | --- | ---: | ---: | ---: | ---: |
| 문헌 내적 대척보수 복원원리 | 모든 대척 위치쌍의 합 271 | 6 | 0 | 0 | 135 / 135 |
| 반대 영역 집계만 | 고리·축·변·섹터·광선 집계 유지, 대척은 해제 | 6 | 0 | 0 | 133 / 135 |
| 고리 내부 보수쌍 | 각 고리의 이웃 위치쌍 합 271; 대척 짝 없음 | 10 | 2 | 0 | 0 / 135 |
| 비대척 전역 보수쌍 | 임의의 고리 횡단 위치 매칭에 합 271; 대척 짝 없음 | 7 | 1 | 2740 | 0 / 135 |
| 6회전 궤도합 | 모든 6회전 궤도의 합 813 | 127 | 2 | 0 | 25 / 135 |
| 45칸 한 隻 + 고정 6순환 값변환 | 45개 궤도에서 동일한 6순환 변환을 적용, 궤도합 813 | 300 | 0 | 0 | 0 / 135 |

이 값은 고정 시드의 재현 가능한 첫 비교값이다. 각 모델은 해공간이 넓으므로 "수학적으로 가능한가"와 "현재 균형 목표에 얼마나 가까운가"를 가르는 용도이며, 전역 최적성 증명은 아니다.

## 모델별 해석 범위

1. **비대척 보수쌍**은 수학적으로 쉽게 성립한다. 그러나 매칭 자체를 고르는 원문 규칙이 없으면 위치 선택이 임의적이다.
2. **고리 내부 보수쌍**은 고리합 `813k`를 자동으로 만든다. `通加洛書數六倍` 및 고리 구조와 잘 맞지만, 이웃 짝을 고르는 이유는 별도로 제시되어야 한다.
3. **6회전 궤도합 813**은 각 고리의 크기가 `6k`인 기하와 자연스럽게 맞고, 고리합도 자동으로 보존한다. 그러나 현재 읽힌 원문에는 `六轉` 또는 궤도별 813을 지시하는 구절이 없다.
4. **반대 영역의 집계만**은 이미 편차 6의 반례가 존재한다. 그러므로 합계 불변량만으로 셀별 대척보수를 논리적으로 대체할 수는 없다.
5. **9고리 낙서 제어 + 별도 배치법**은 반례와 고리 내부 모델 모두에서 살아남는다. 즉 `洛書數六倍`가 고리 크기·순서를 직접 제어한다는 점은 강하지만, 그것만으로 값 배치법을 하나로 정하지는 않는다.
6. **45칸 한 隻을 6회전으로 생성**하는 강한 모델은 실제로 구현 가능하지만, 고정 값변환까지 요구하면 현재 균형 목표와의 충돌이 가장 컸다. 이것은 원문 반증이 아니라, 현재 목적함수와의 상대적 비용이다.

## 직전 천수용오도 재인쇄의 비교 근거

육고도 바로 앞의 천수용오도 계열 전사는 다음을 말한다.

> 去中宮十五
>
> 外合得二百一十六
>
> 無宮各得五十四爲六九之數
>
> 二十二子作二十五子用同前

여기에는 두 개의 직접 산술 연결이 있다.

\[
216=4\times54,\qquad54=6\times9.
\]

따라서 재인쇄를 육고도와 연결해 읽는다면, 가장 강하게 지지되는 것은 다음 세 가지다.

- `去中宮`과 `虛一`: 중심을 비우거나 제외한 뒤 외부 구조를 계산하는 수법.
- 외부 영역의 **등집계**: 54씩의 부분합을 만들어 전체 216을 구성하는 방식. 이는 "반대 영역의 집계합" 및 "고리 제어 + 별도 배치"에 직접적인 내부 선례를 준다.
- `五十四爲六九之數`: 육고도의 외주 54와 `6×9`를 바로 앞에서 명시하는 수적·어휘적 연결.

반대로 이 재인쇄는 셀별 `v(c)+v(-c)=271`, 임의의 비대척 매칭, 6회전 값변환, 또는 45칸 섹터 생성법을 직접 명령하지 않는다. 특히 저장소의 천수용오도 도식 분석은 스스로 "수학적 규칙 변용 연구 모델"이라고 밝히므로, 그 현대 배치에서 얻은 좌우합·오행 패턴을 원전 명령으로 격상하지 않았다.

## 현재의 비교 판정

원문 정합을 분리하면 다음과 같다.

| 조건군 | 수학적 양립 | 직전 재인쇄와의 직접 연결 | 값-위치 대응의 문헌 내적 지지 |
| --- | --- | --- | --- |
| 대척보수 복원원리 | 매우 좋음 | 간접: 중심 제외·54=6×9와 양립 | 가장 강함: 낙서 계열 보수 구성·135쌍 대응 |
| 반대 영역 집계만 | 매우 좋음 | **직접적으로 가장 가까움**: `外合`·`各得五十四` | 셀별 규칙으로는 약함 |
| 고리 내부 보수 | 좋음 | 54=6×9와 양립 | 짝짓는 위치 규칙이 없음 |
| 비대척 전역 보수 | 좋음 | 직접 연결 없음 | 매칭 선택이 임의적 |
| 6회전 궤도합 | 좋음 | 6과 9에는 양립, 회전 명령은 없음 | 흥미로운 기하 경쟁안 |
| 45칸 6회전 생성 | 성립 | 직접 연결 없음 | 가장 강한 추가 가정 |

결론적으로 천수용오도 재인쇄는 **집계 균형과 54=6×9의 직전 선례**를 상당히 보강한다. 하지만 이것은 대척보수 원리를 대체하기보다, "고리 제어와 영역 집계가 값 배치와 구별될 수 있다"는 대안 공간을 명확히 한다. 현 단계에서 가장 덜 추가 가정을 요구하면서 낙서 계열의 위치-값 구성 선례까지 보존하는 것은 여전히 문헌 내적 대척보수 복원원리다. 다만 집계만으로는 그 원리를 강제하지 않는다는 경계도 이번 경쟁 실험에서 다시 확인된다.
