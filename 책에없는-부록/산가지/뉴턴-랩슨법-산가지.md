# 뉴턴-랩슨법을 산가지로 계산하기

`x³ − 2 = 0`의 양의 근을 뉴턴-랩슨법으로 구할 수 있다. 보통은 다음 갱신식을 쓴다.

    xₙ₊₁ = xₙ − (xₙ³ − 2) / (3xₙ²)

하지만 산가지에서는 소수를 그대로 놓기보다 자릿수를 고정한 정수로 바꾸는 편이 낫다. 소수 여섯째 자리까지 보관하려고 `S = 1,000,000`을 정하고, `a = Sx`로 둔다. 그러면 세제곱근을 구하는 뉴턴 반복은 다음 정수 계산으로 쓸 수 있다.

    aₙ₊₁ = (2aₙ + 2S³ / aₙ²) / 3

나눗셈의 몫만 취하면 모든 중간값은 정수다. 즉, 산가지에는 `a`, `a²`, `2S³ ÷ a²`와 새 `a`를 차례로 놓으면 된다. 마지막에 `a`의 소수점만 여섯 자리 왼쪽으로 옮긴다.

예를 들어 `a₀ = 1,250,000` (`x₀ = 1.25`)에서 시작하면 다음과 같이 빠르게 가까워진다.

| 반복 | 산가지 정수 `a` | 읽는 값 `x = a / S` |
| --- | ---: | ---: |
| 0 | 1,250,000 | 1.250000 |
| 1 | 1,260,000 | 1.260000 |
| 2 | 1,259,921 | 1.259921 |

`뉴턴-랩슨법-산가지.py`는 이 과정을 산가지 모양으로 애니메이션한다. 실행하려면 Matplotlib가 설치된 환경에서 다음을 실행한다.

    python3 뉴턴-랩슨법-산가지.py

정수 나눗셈을 쓰므로 표시 자릿수보다 더 높은 정확도가 필요하면 `S`를 10,000,000 또는 그 이상으로 키우면 된다.
