# 산가지로 3차 방정식의 근 구하기

예제는 계수와 계산 순서가 모두 단순한 다음 3차 방정식으로 잡는다.

    x³ − 2 = 0

양의 근은 세제곱근 2, 즉 약 1.2599이다. 여기서는 그 값을 미리 쓰지 않고 산가지의 계수열과 부호만으로 앞자리부터 구한다.

## 1. 정수 자리

계수열은 `[1, 0, 0, -2]`이다. 차례로 x³, x², x, 상수항을 뜻한다.

`f(1) = -1`, `f(2) = 6`이므로 양의 근은 1과 2 사이이다. 따라서 정수 자리는 1이다.

이제 남은 소수 부분만 다루기 위해 `x = 1 + y`로 둔다. 전개는 긴 곱셈 대신 `(1 + y)³`을 쓰면 바로 정리된다.

    (1 + y)³ − 2 = y³ + 3y² + 3y − 1

즉, 새 계수열은 `[1, 3, 3, -1]`이고 `0 < y < 1`이다. 이런 식으로 이미 찾은 자리를 보조 미지수로 떼어 내면, 사원술에서 보조 원을 두어 계산을 정리하는 발상과 마찬가지로 다음 계산이 짧아진다.

## 2. 첫째 소수 자리

`y = u / 10`으로 두고 모든 항에 1000을 곱하면 소수점이 사라진다.

    u³ + 30u² + 300u − 1000 = 0

`u = 2`일 때 값은 -272, `u = 3`일 때 값은 197이다. 근은 2와 3 사이이므로 첫째 소수 자리는 2이다. 지금까지 `x = 1.2…`를 얻었다.

## 3. 둘째와 셋째 소수 자리

매번 처음부터 큰 식을 전개할 필요는 없다. 이미 찾은 자리 `0.2`를 고정하고 남은 한 자리를 새 변수로 둔다.

    y = 0.2 + v / 100

위 식을 `y³ + 3y² + 3y − 1`에 넣고 1,000,000을 곱하면 다음 계수열이 된다.

    v³ + 360v² + 43200v − 272000 = 0

`v = 5`에서는 -48,125이고 `v = 6`에서는 376이다. 둘째 소수 자리는 5, 즉 `x = 1.25…`이다.

같은 치환을 한 번 더 하면 셋째 자리 후보를 비교할 수 있다. 계산 결과 `x = 1.259…`이며, 계속하면

    x ≈ 1.259921

을 얻는다. 실제로 이 값의 세제곱은 2에 매우 가깝다. 음의 근은 `−1.259921…`이다.

## 계산에서 볼 점

산가지에는 한 단계마다 그 식의 계수열만 놓으면 된다. 핵심은 다음 세 동작의 반복이다.

1. 두 이웃한 정수에 대입해 부호가 바뀌는 곳을 찾는다.
2. 확정한 자리를 새 변수로 분리한다.
3. 분모의 10의 거듭제곱만큼 곱해 다시 정수 계수열로 만든다.

따라서 큰 계수가 나타나도 산가지의 자릿수만 늘어날 뿐, 계산 규칙 자체는 바뀌지 않는다.
